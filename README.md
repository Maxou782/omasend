## 🧰 Troubleshooting Tips

Sometimes things do not go perfectly the first time. Here are a few quick fixes for common hiccups:

- **I Cannot See the Other Device**: Make sure both devices are connected to the **same Wi-Fi network**. If you are on a guest network or a public network (like a coffeeshop), some routers block device-to-device communication. Try switching to a private network.

>

- **The Transfer Is Taking Too Long**: Large files take time. Make sure you are reasonably close to your Wi-Fi router. If you have a lot of devices using the same network, it may slow things down a bit. Patience is key.


- **My Antivirus Blocked the Download**: Sometimes antivirus software gets a little overzealous. If this happens, check your antivirus quarantine or blocked history, and choose to "Allow" or "Restore" the file. Then try downloading again.
